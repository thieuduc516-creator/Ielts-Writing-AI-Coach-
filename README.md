# IELTS Writing AI Coach Pro

Professional static GitHub Pages demo.

## Features
- Choose Your Level: Beginner, Intermediate, Advanced
- IELTS Task 1 and Task 2 practice
- Essay editor
- Estimated band demo
- Sentence-by-sentence correction
- Band vocabulary ladder
- Gamified points
- Export feedback report

## Deploy
Upload these files to GitHub and enable GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)
